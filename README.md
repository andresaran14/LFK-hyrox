# HYROX Tracker LFK — PWA

Ready to deploy to GitHub Pages.

## Files
- `index.html` — main app
- `manifest.webmanifest` — PWA manifest
- `sw.js` — offline/service-worker cache
- `icons/` — iOS, Android and favicon assets
- `logo.svg` / `logo-wordmark.png` — refined logo concept #7

## Data
Workout sessions are stored in the browser's `localStorage`. No server or database is required.

## GitHub Pages
Upload all files/folders to the root of the repository and enable GitHub Pages from the repository's Pages settings.

Once served over HTTPS, the app can be added to the iPhone/iPad Home Screen from Safari.
